# Week 7 Assignment: My Notes & The Report Builder

## Project Files

- **my_notes.py** – Writes, appends, reads, and counts notes in a text file.
- **my_notes.txt** – Stores the four notes created by the notes program.
- **report_builder.py** – Reads learner data from a CSV file and generates a report.
- **hubs.csv** – Contains learner names, hub names, and scores.
- **report.txt** – Contains the learner report, including total learners, passes, failures, and average score.
- **README.md** – Provides information about this assignment and its files.
